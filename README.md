# AI/ML Engineer Portfolio

A futuristic, responsive Junior AI/ML Engineer portfolio built with **HTML, CSS and JavaScript**.

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Install the **Live Server** extension if needed.
3. Open `index.html`.
4. Right-click → **Open with Live Server**.

## Customize

Search the project for:
- `Your AI/ML Engineer`
- `Your Name`
- GitHub / LinkedIn links
- Email address
- Project details

Your CV is in `resume/Usman_Saqib_Resume.pdf`. To update it, replace that file (keep the same name). "Download Resume" buttons are on the Home, Experience and Contact pages.

## Main pages

Home · About · Skills · Projects · Experience · Education · Certificates · Contact

## Dark / Light mode
The ☾ / ☀ button in the navbar switches the theme on every page and remembers your choice (saved in the browser).
Colors for both themes are variables at the top of `css/style.css` (`:root` for dark, `:root[data-theme="light"]` for light).
